# Professional framework references

The [TRAP-18 developer overview](https://drreidmeloy.com/training/trap-18/) describes a lone-actor terrorism assessment protocol with proximal warning behaviors and longer-term characteristics. Public examples include pathway, fixation, identification, and last-resort behavior. Each manual user needs the appropriate license. The protocol is not a keyword list or an automatic classifier for online communities.

The [WAVR-21 developer overview](https://wavr21.com/wavr-21/) describes structured professional judgment for workplace and campus targeted violence. It includes risk and protective considerations, recent changes, and organizational context. It does not yield a quantitative risk score. Training and work within professional competence matter.

ZERO_NIHL uses those references to explain why observable behavior, change, context, corroboration, and protective information belong in a review process. It does not reproduce numbered items, coding criteria, manuals, forms, or decision thresholds.

| Project domain | Public conceptual connection | Limitation |
| --- | --- | --- |
| Research and preparation | TRAP-18 pathway; broader targeted-violence planning | Project grouping, not instrument coding |
| Prior-attacker emulation | TRAP-18 identification; FBI mobilization research | Academic interest alone does not establish emulation |
| Repeated target attention | Public fixation concept | A word match cannot establish a behavioral pattern |
| Case context and protective information | WAVR-21 professional judgment approach | No automated concern level or score |

These connections are project interpretations, not validated mappings. Neither framework's validity is transferred to this dataset. NVE-related coercion and victimization require safeguarding expertise beyond a general violence-assessment vocabulary.
